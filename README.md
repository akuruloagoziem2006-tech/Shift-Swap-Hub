# ShiftSwap


**The easiest way for shift-based teams to swap shifts.**


ShiftSwap helps teams in hospitals, restaurants, retail, and similar industries post available shifts, request swaps, and get manager approvals — without the chaos of group chats and phone calls.


🌐 Live Demo: [https://shift-swap-hub-alpha.vercel.app](https://shift-swap-hub-alpha.vercel.app)

🎮 **Quick Demo:** Sign in with `demo@shiftswap.app` / `demo1234` to explore the app

## Features

- **📅 Post Available Shifts** — Share shifts you want to give away
- **🔍 Browse & Request** — Find and request coverage from colleagues
- **📆 Calendar View** — See all shifts at a glance with color-coded status
- **✅ Manager Approvals** — One-click approval workflow for supervisors
- **👤 User Profiles** — Manage roles, departments, and preferences
- **🔐 Secure Authentication** — Google, GitHub, or email/password
- **🌙 Dark Mode** — Beautiful dark theme optimized for all devices
- **📱 Responsive** — Works perfectly on desktop and mobile

## Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm
- A [Supabase](https://supabase.com/) project

### Quick Start

```bash
# Clone the repository
git clone https://github.com/akuruloagoziem2006-tech/Shift-Swap-Hub.git
cd Shift-Swap-Hub

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Edit .env.local with your Supabase credentials

# Run database setup in Supabase SQL Editor
# (Copy contents of SETUP_DATABASE.sql)

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.
