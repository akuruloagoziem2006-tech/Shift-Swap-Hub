# ShiftSwap


**The easiest way for shift-based teams to swap shifts.**


ShiftSwap helps teams in hospitals, restaurants, retail, and similar industries post available shifts, request swaps, and get manager approvals — without the chaos of group chats and phone calls.


🌐 Live Demo: [https://shift-swap-hub-alpha.vercel.app](https://shift-swap-hub-alpha.vercel.app)


---


## Features


- Post available shifts
- Browse and request shift swaps
- Calendar view of all shifts
- Manager approval workflow
- User profiles & departments
- Google & GitHub authentication
- Dark mode + responsive design


---


## Tech Stack


- **Frontend**: Next.js 14 (App Router)
- **Backend / Auth / Database**: Supabase
- **Styling**: Tailwind CSS + shadcn/ui
- **Deployment**: Vercel


---


## Getting Started


1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables (see `.env.example`)
4. Run the database setup script in Supabase
5. Start the development server:
   ```bash
   npm run dev
   ```
